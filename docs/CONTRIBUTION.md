# 团队贡献说明

> 说明：以下内容为课程项目提交版分工模板。请在最终提交前，将“成员A / 成员B / 成员C / 成员D”替换为真实姓名。

## 1. 团队成员与总体贡献度

| 团队成员 | 主要角色 | 核心负责内容 | 贡献度 |
| --- | --- | --- | --- |
| 成员A | 项目负责人 / 数据工程 | 数据获取、数据清洗、标签构建、实验统筹 | 30% |
| 成员B | 特征工程与建模负责人 | 预处理、特征筛选、样本处理、风险分类模型 | 25% |
| 成员C | 额度模型与评估负责人 | 额度测算模型、评估分析、可解释性、结果整理 | 25% |
| 成员D | LLM 与系统集成负责人 | Deepseek 接入、策略生成、Demo 开发、文档整合 | 20% |

## 2. 按阶段拆分的工作内容

### 第一阶段：项目选题与方案设计

#### 成员A

- 负责金融风控业务场景调研
- 明确项目目标、风险分级任务和额度测算任务
- 规划整体数据流与实验路线

#### 成员B

- 梳理特征工程与建模方案
- 设计预处理、筛选与采样模块结构

#### 成员C

- 确定分类与回归评估指标体系
- 规划模型调参与结果分析框架

#### 成员D

- 设计 LLM 应用场景与系统 Demo 架构
- 规划最终展示路径与交互页面结构

### 第二阶段：数据集处理与标签构建

#### 成员A

- 负责数据集下载脚本编写
- 完成原始字段脱敏与时序切分
- 输出 `train / val / test` 数据集

#### 成员B

- 协助分析字段类型与数据质量
- 支持标签构建所需字段清单梳理

#### 成员C

- 参与贷前风险标签和额度标签规则校验
- 协助审查标签是否满足建模需求

#### 成员D

- 记录数据处理逻辑，整理 Notebook 展示内容
- 负责后续 Demo 所需字段映射整理

### 第三阶段：特征工程与风险分类模型

#### 成员A

- 提供业务字段语义支持
- 协助识别高风险相关特征

#### 成员B

- 主导 `CreditDataPreprocessor` 开发
- 主导 `CreditFeatureSelector` 开发
- 主导 `CreditSampler` 开发
- 实现风险分类模型训练与调参流程

#### 成员C

- 协助评估分类指标表现
- 参与模型结果分析与误差归因

#### 成员D

- 整理分类模型实验结果和展示素材
- 支持可视化输出接入 Demo

### 第四阶段：额度测算模型与评估分析

#### 成员A

- 从业务角度提供额度约束规则建议

#### 成员B

- 协助准备建模输入特征
- 支持回归模型特征接口对齐

#### 成员C

- 主导 `CreditScorer` 开发
- 主导回归模型训练、调参与评估
- 实现监管硬约束嵌入逻辑
- 负责 SHAP 解释分析和关键图表输出

#### 成员D

- 负责将额度结果接入前端展示
- 负责演示逻辑串联和结果导出设计

### 第五阶段：LLM 策略生成与系统集成

#### 成员A

- 审核 LLM 输出是否符合业务场景

#### 成员B

- 配合整理模型输出字段与策略模块输入接口

#### 成员C

- 提供风险等级与额度结果给策略模块使用

#### 成员D

- 主导 `DeepseekClient` 开发
- 主导 `CreditStrategyGenerator` 开发
- 完成合规复核逻辑设计
- 完成 `CreditRiskPipeline` 全链路系统集成
- 完成 Streamlit Demo 页面开发

### 第六阶段：文档撰写与课程答辩准备

#### 成员A

- 负责项目背景、业务目标、数据处理部分撰写

#### 成员B

- 负责特征工程与风险分类模型部分撰写

#### 成员C

- 负责额度模型、评估结果、创新点分析撰写

#### 成员D

- 负责系统集成、LLM 模块、PPT 与演示流程整理

## 3. 工作边界说明

- 成员A：聚焦业务理解、数据处理、标签定义与项目统筹
- 成员B：聚焦特征工程、不平衡处理、风险分类建模
- 成员C：聚焦额度测算、评估分析与解释性结果
- 成员D：聚焦 LLM 模块、全链路集成、Demo 展示与文档收口

## 4. 协作机制说明

- 采用模块化开发方式，避免多人同时修改同一核心文件
- 使用统一的数据字段命名规范，减少接口不一致
- 以 Notebook 验证阶段结果，以 `src/` 下脚本沉淀可复现代码
- 最终由项目负责人统筹版本整合和课程材料提交

## 5. 贡献度评估依据

- 工作量占比
- 核心模块复杂度
- 对最终成果完整性的影响程度
- 文档、演示与答辩材料的实际投入
