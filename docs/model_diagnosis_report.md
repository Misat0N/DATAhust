## 自动诊断结论
- 当前模型存在明显的不平衡退化或主类挤压现象。
- 模型偷懒：正常类预测占比超过90%，且其他类别召回率均低于10%
- 严重不平衡退化：Weighted-F1 与 Macro-F1 差值为 0.617587，超过 0.3
